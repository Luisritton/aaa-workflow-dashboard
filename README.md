# ⚡ AAA Workflow Dashboard

Painel corporativo moderno e responsivo desenvolvido para o monitoramento em tempo real de fluxos de automação e agentes de inteligência artificial de uma **Agência de Automação de IA (AAA)**. Projeto desenvolvido como parte de um programa avançado de Engenharia de Produto.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semantic**: Estruturação limpa e acessível.
* **CSS3 Moderno**: Design system customizado com variáveis globais, Flexbox, tipografia Google Fonts (*Inter*) e indicadores visuais de status (*Badges*).
* **JavaScript Vanilla (ES6+)**: Funções assíduas, requisições HTTP, manipulação avançada de DOM e arrays (`filter`).
* **Async/Await & Fetch API**: Consumo de dados de servidores externos com tratamento seguro de erros (`try/catch` e validação de `response.ok`).

## 📌 Funcionalidades

- **Conexão Assíncrona com API**: Busca de dados em tempo real com indicador visual de carregamento.
- **Filtro Dinâmico Instantâneo**: Mecanismo de busca que filtra agentes e automações instantaneamente enquanto o usuário digita.
- **Tratamento Robusto de Erros**: Interceptação de falhas de rede e validação de status HTTP.
- **Métricas e Contadores**: Atualização dinâmica do total de registros ativos no painel.

## 💻 Como Executar o Projeto

1. Clone o repositório ou faça o download dos arquivos para a sua máquina.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` ou abra-o utilizando a extensão **Live Server** no seu VS Code.
